# Edilson Dantas — Portfólio

React + TypeScript + Vite + SCSS. Veja `IMPLEMENTATION_STATUS.md` para status, pendências e configuração.

```bash
npm install
cp .env.example .env
npm run dev
```

## Estrutura

- `src/app` — App, layout e rotas
- `src/components` — Header, menu, modal de contato, formulário, footer, botões, toggles
- `src/sections` — seções da Home
- `src/pages` — páginas (Home, Projetos, Sobre, Contato, Case, 404)
- `src/styles` — tokens, temas (claro/escuro), globais e animações
- `src/locales` — traduções pt-BR e en
- `src/data` — projetos, serviços, navegação e dados de contato
